# Pulse

A one-page website for the ECG arrhythmia classifier: the story of the project, an in-browser playground that runs the trained CNN on real heartbeats, and the results.

## Quickstart

```
cd web
npm install
npm run dev
```

## What you'll see

Open http://localhost:5173. A red ECG trace draws across the hero, then the page scrolls through the problem, the data, the pipeline, the playground (press "Shuffle beat", the mascot reacts to the prediction) and the results. The model loads from `public/models` and runs on your CPU through onnxruntime-web, so the playground works offline.

## Requirements

- Node 20 or newer (built on Node 26)
- A modern browser with WebAssembly (any current Chrome, Safari, Firefox, Edge)

## Troubleshooting

| Error | Fix |
| --- | --- |
| `npm run dev` says port 5173 is in use | Run `npm run dev -- --port 5174` and open that port instead |
| Playground stays on "loading model…" | Check `public/ort/` holds `ort-wasm-simd-threaded.wasm`. Restore it with `cp node_modules/onnxruntime-web/dist/ort-wasm-simd-threaded.{wasm,mjs} public/ort/` |
| No beats appear, or the gallery is empty | `public/beats.json` and `public/gallery.json` are written by `python web_export.py` in the repo root (needs the `.venv` from the main README) |

## Project structure

- `src/App.tsx` — page order, nav and footer
- `src/sections/` — one file per section: Hero, Stats, Problem, Data, Pipeline, Playground, Results
- `src/components/Mascot.tsx` — Beat, the mascot; plays the five EffectCraft Lotties from `public/lottie`
- `src/components/art.tsx` — the three illustrations, generated by `art/illustrations/gen.py`
- `src/lib/infer.ts` — loads the two ONNX models and runs a beat through them
- `src/lib/wave.ts` — SVG path helpers for drawing beats
- `src/data/results.json` — the metrics the Results section reads
- `public/models/` — `cnn_seen.onnx` and `cnn_unseen.onnx`, exported by `web_export.py`
- `art/` — sources: mascot SVG generator, EffectCraft projects, VectorCraft proofs, PhotoCraft OG card, SoundCraft heartbeat

## Build

```
npm run build
npm run preview
```

`dist/` is a static site. Deploy it anywhere that serves files (Vercel, Netlify, GitHub Pages).
